# Frontend (Communication module)

1. Extract this zip over your `frontend/` folder (overwrite `app/layout.tsx`, `app/page.tsx`, `app/globals.css`).
2. Copy `.env.local.example` to `.env.local` (API URL = your backend, default http://localhost:5000).
3. `npm run dev`  -> http://localhost:3000

Pages: /login, /register, /dashboard, /announcements (+ /new, /[id]/edit),
/emails/compose, /emails/history, /templates
